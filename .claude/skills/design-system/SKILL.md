# branch-console 디자인 시스템 규격

## 토큰 (Tokens.kt 단일 소스 — 화면 코드에 리터럴 금지)
- 국면 팔레트(라이트/다크 쌍): GREEN #1B8A5A/#4ADE80 · AMBER #B45309/#FBBF24 · ORANGE #C2410C/#FB923C · RED #B91C1C/#F87171.
  배경·서피스는 뉴트럴 슬레이트 계열, 국면색은 배지·게이지·위젯 강조에만(면적 절제). 모든 조합 본문 대비 ≥ 4.5:1 검증.
- 이중 부호화: 국면은 색 + 라벨 + 전용 아이콘(●/▲/◆/■ 계열)로 동시 표기 — 색맹 대응.
- 타이포: 시스템 Sans + 숫자는 tabular figures(FontFeature "tnum"). 스케일: display 28 / title 20 / body 15 / label 12 / mono-num 강조 34.
- 간격 4dp 그리드(4·8·12·16·24·32), 모서리 12dp(카드)·8dp(칩), 엘리베이션 대신 헤어라인+틴트.
- 모션 토큰: fast 120ms(칩·배지) · base 200ms(카드·전환) · phase 300ms(국면 게이지, EaseOutCubic). 과장·바운스 금지.

## 화면 규칙
- 홈 3초 규칙: 국면·composite·상위 발화 지표 3·데이터 as_of가 스크롤 없이 보인다.
- 상태 4종(스켈레톤/빈/오류/정상) 필수. PREVIEW 데이터는 배너+점선 테두리로 확정치와 시각적으로 구분(D-17).
- 결측·스테일 지표는 회색 처리 + 배지(수치 은폐 금지 — 정직한 계기판).
- 터치 타깃 ≥ 48dp, 글꼴 스케일 1.3× 무파손, TalkBack 라벨은 "국면 오렌지, 복합 47점" 식 자연문.

## 품질 바
macrobenchmark 콜드 < 2s·정크 < 1%, 위젯 갱신 < 1s. 스크린샷 보고(라이트·다크). §2.5 상용 체감 검사 통과가 완료 정의다.
